# Roadmap

Ideas under consideration, in no particular order. None is a commitment; priorities follow user issues and
changes in the standards.

- More stack recipes: Node.js/Express, Django, Rails, ASP.NET, Spring; WordPress-specific hardening.
- Windows hosting: IIS hardening and a PowerShell installer (today: manual copy commands).
- Machine-readable checklist (YAML/JSON) so audits can be tracked by tooling.
- Agent evaluation scenarios: small vulnerable sample apps and prompts to measure whether agents follow the rules.
- Nginx configuration test harness in CI (needs generated test certificates).
- Signed releases and build provenance attestations in addition to checksums.
- Translations of the checklist and rules.
- Additional adapters (other agent tools) once their instruction formats are verified.

Suggest or vote on items by opening an issue using the content request form.
