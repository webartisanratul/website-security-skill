# Code of Conduct

## Our pledge

We want this project to be a respectful, harassment-free space for everyone who contributes or uses it,
regardless of experience, background, identity or employer. Technical disagreement is welcome; personal attacks
are not.

## Expected behaviour

- Be courteous and assume good faith; critique ideas and evidence, not people.
- Back claims with primary sources. Say "I could not verify this" when that is the case.
- Accept that maintainers must say no to changes that do not fit the project's scope or quality bar.
- Respect others' time: search existing issues before opening new ones.

## Unacceptable behaviour

- Harassment, discrimination, threats, doxxing or sustained disruption.
- Using the project to target, probe or attack systems you do not own or are not authorised to test. Offensive
  requests are out of scope and will be closed.
- Posting secrets, personal data or non-public vulnerability details in public issues.
- Submitting fabricated references, invented URLs or unverified claims as fact.

## Scope

This applies to all project spaces (issues, pull requests, discussions) and to public representation of the
project.

## Enforcement

Report concerns privately to the maintainers using the contact in [SECURITY.md](SECURITY.md). Maintainers will
review in good faith, protect reporter privacy, and may warn, edit or remove content, or restrict participation.
Decisions can be appealed to another maintainer if one exists.

This is a short code written for this project in the spirit of widely used community codes of conduct.
